# paperless-tarmed

Reads Swiss **"Justificatif de remboursement"** / **"Rückforderungsbeleg"** forms
(TARMED / TARDOC) in
[Paperless-ngx](https://docs.paperless-ngx.com) and fills custom fields and,
optionally, the title. Runs as a webhook for new documents and as a CLI for
audits and backfills. First-time setup: **[INSTALL.md](INSTALL.md)**; Paperless
itself: [guide 07](../../docs/guides/07-paperless.md).

- **Ports**: none published; in-cluster `http://paperless-tarmed:8000/hook` and `/health`.
- **Network**: `proxy` (external), only because Paperless's `webserver` is there.
- **Caddy**: no route, by design; the `*.<internal-domain>` catch-all 404s it.
- **Volume**: `PAPERLESS_TARMED_DATA` → `/data` (cache, journal, tariff table), owned by uid 1000.
- **Image**: built on the NAS by the `build-images` job; no registry.
- **Secrets**: `PAPERLESS_TOKEN`, `PAPERLESS_TARMED_WEBHOOK_SECRET` in Portainer's stack environment. The secret's other half is in the Paperless workflow (Paperless's database), in neither git nor Portainer: record it wherever rotations are tracked.

## What it extracts

| Value             | Source                                                       |
| ----------------- | ------------------------------------------------------------ |
| `patient`         | `Patient Nom … / Prénom …` (given name)                      |
| `treatment_date`  | **oldest** of the `Traitement` range and all line-item dates |
| `total`           | `Montant de la facture:` (4.5G) or `A payer CHF` (4.0 H)     |
| `total_unrounded` | `Montant total`, as printed                                  |
| `category`        | from identifiers, see below                                  |
| `provider`        | short provider name                                          |
| `provider_gln`    | the provider's 13-digit GLN                                  |

`PAPERLESS_TARMED_FIELDS` maps any subset to your field names (`a=b,c=d`, or JSON
if a name has a comma). Extraction is label-anchored regex over the text layer Paperless
already made: no OCR, no ML, no LLM. A value failing a plausibility check (`PAPERLESS_TARMED_MAX_*`) is never
written; the document is tagged instead.

### Category

From the **official code catalogues** — no configuration, no reading of text
(`catalogue.py`). Each service line is a _service_ (a Tarif 590 method, a
TARDOC or TARMED chapter, physio, psy, hospital…), a _basic position_ (TARDOC
domain `A`, TARMED `00`/`01`/`35`, Tarif 590 chapter 1) or a _supply_ (medicines,
materials, lab). The first group present in that order wins, and within it
**the category with the largest total**:

| Bill                                                     | Category                        |
| -------------------------------------------------------- | ------------------------------- |
| osteopathy: 590 `1200` + `1203`                          | Ostéopathie                     |
| GP consultation + vaccines                               | Médecin (vaccines are supplies) |
| paediatric exam (`CG`) 92.56 + consultation (`CA`) 18.05 | Pédiatrie                       |
| GP basic positions (`00`) + lab                          | Médecin (basic outranks supply) |
| lab alone                                                | Labo                            |

Where the data comes from:

| Catalogue           | Official source                          | In `data/catalogue.json`                             |
| ------------------- | ---------------------------------------- | ---------------------------------------------------- |
| TARMED 1.09 (`001`) | tariff structure PDF (sumex1.net)        | all 447 chapters and sub-chapters with their titles  |
| TARDOC (`007`)      | OAAT's browser, tardoc-online.ch         | all 65 domains and chapter groups, French titles     |
| Tarif 590           | SASIS / santéservices, `tarif-590.xlsx`  | all positions: chapter → tier, French text → label   |
| tariff types        | Forum Datenaustausch (`refresh-tariffs`) | reference only: labels are hardcoded in `tariffs.py` |

The only editorial part is in `catalogue.py`: a short label per TARDOC/TARMED
chapter (e.g. TARMED `08` _Auge_ → `Ophtalmo`), and for Tarif 590 methods whose
official name is over 20 characters (`1052` _Massage des zones réflexes du
pied_ → `Réflexologie`). Tests check both cover the official data.

`paperless_tarmed/data/catalogue.json` is generated by
`uv run --extra dev python scripts/build_catalogue.py` (sources inside); don't
hand-edit it. A code it doesn't cover gets the tariff type's label
(`PAPERLESS_TARMED_CATEGORIES` relabels), and `report` lists it under **CODES
NOT IN THE CATALOGUE TABLES**.

### Provider name and title

Provider name, by one rule on the printed name: an acronym in parentheses
(`(CRG)`); else an organisation (legal form or Hôpital/Clinique/Centre/…) gives
its initials if 3+ words (`Hôpitaux universitaires de Genève` → `HUG`) or its
first name word (`Viollier Weintraub SA` → `Viollier`); else a person's surname,
titles dropped (`Docteur Lucien MUSTERMANN` → `Mustermann`).
`PAPERLESS_TARMED_GLN_OVERRIDES` can pin a name by GLN.

Title: `PAPERLESS_TARMED_TITLE` (default `{patient} - {category} - {treatment_date} - {provider}`),
e.g. `Anna - Ostéopathie - 2025-03-15 - Muster`. Unfillable segments are dropped.

### What gets written

- Custom fields **fill blanks only**, unless `apply --overwrite` /
  `PAPERLESS_TARMED_WEBHOOK_OVERWRITE=1`.
- Titles only with `apply --title` / `PAPERLESS_TARMED_WEBHOOK_TITLE=1`.
- The review tag goes only on a justificatif with an extraction warning (a skipped
  or substituted value, a missing provider or service table, several justificatifs).
  A document with no form page is left alone, unless its Paperless type is
  `PAPERLESS_TARMED_DOCUMENT_TYPE`.
- The done tag (`tarmed`) goes on a justificatif read with nothing to review.
- A **note** on the document records each outcome with its date and time: the
  reasons when it is first tagged for review (or the webhook crashed), the
  values and title written on success. A run that writes nothing adds no note.
  A note is tried once, never retried: a retry could post it twice.
- Every write goes to `/data/cache/journal.jsonl` (locally `.cache/`): new field values, old and new title.
- Writes are retried (3 attempts). A document that still fails does not stop
  `apply`: failures are listed, exit code 1; re-run the same command to retry them.

## CLI

In the container: `docker exec paperless-tarmed paperless-tarmed <command>`.
Locally, `.env` is read (`--env-file` for another); real environment variables win.

| Command             | Does                                                                                                                           |
| ------------------- | ------------------------------------------------------------------------------------------------------------------------------ |
| `extract FILE.pdf…` | Offline. Shows values, GLN, category source. `--json`, `--show-text`.                                                          |
| `fields`            | Values, your custom fields, the mapping, document types.                                                                       |
| `pull`              | Download matching documents into the cache. `--refresh` re-downloads.                                                          |
| `report`            | Quality table, then categories found and codes missing from the catalogue tables. `--only fail,differ`, `--csv`, `--out FILE`. |
| `apply`             | **Dry run** unless `--apply`. `--overwrite`, `--title`, `--no-tags`, `--journal PATH`.                                         |
| `serve`             | The webhook (container default). `--host`, `--port 8000`, `--log-level`.                                                       |
| `refresh-tariffs`   | Show what changed in the official tariff list, then save it. `--dry-run`.                                                      |

Selection flags for `pull`, `report`, `apply`: `--document-type NAME|ID`, `--tag`,
`--query`, `--id N` (repeatable), `--since 2y|18m|90d|6w|YYYY-MM-DD`, `--limit N`.
Any of them selects from Paperless (defaults: `PAPERLESS_TARMED_DOCUMENT_TYPE`,
`_SINCE`) and downloads what the cache lacks; the whole archive is refused. **With
none, `report` and `apply` read only the local cache**, not the archive.

`report` verdicts per value: `ok` (Paperless already has it), `fill` (empty, would
be written), `differ` (Paperless holds something else: read these first), `fail`
(nothing usable, with the reason).

`scripts/fire-hook.sh <id>…` replays the webhook for existing documents. It
writes, and "accepted" is not "extracted": read `docker logs`. Dry run: `apply --id <id>`.

## Configuration

All variables, with defaults: [.env.example](.env.example). The required ones are
set in [INSTALL step 3](INSTALL.md#3-deploy-the-stack-in-portainer). Others worth knowing:

| Variable                                               | Purpose                                                                                                    |
| ------------------------------------------------------ | ---------------------------------------------------------------------------------------------------------- |
| `PAPERLESS_TARMED_PATIENTS`, `_ALIASES`                | allow-list (a name not on it is refused); nickname → name                                                  |
| `PAPERLESS_TARMED_TITLE`                               | title template; empty disables titles                                                                      |
| `PAPERLESS_TARMED_WEBHOOK_OVERWRITE`, `_WEBHOOK_TITLE` | default `0`; see Gotchas                                                                                   |
| `PAPERLESS_TARMED_CATEGORIES`, `_GLN_OVERRIDES`        | relabel tariff types; pin a provider name                                                                  |
| `PAPERLESS_TARMED_REVIEW_TAG`                          | default `extraction-failed`; empty disables tagging                                                        |
| `PAPERLESS_TARMED_DONE_TAG`                            | default `tarmed`; empty disables it                                                                        |
| `PAPERLESS_TARMED_MAX_*`, `_FUTURE_TOLERANCE_DAYS`     | plausibility bounds                                                                                        |
| `PAPERLESS_TARMED_VERIFY_SSL`                          | `0` for a self-signed certificate                                                                          |
| `PAPERLESS_TARMED_NTFY_URL`, `_TOKEN`, `_TOPIC`        | push "Bill processed" / "needs review" to ntfy; off while URL or token is empty; topic default `paperless` |
| `PAPERLESS_TARMED_NTFY_PATIENT`                        | default `0`: the patient's name stays off the lock screen                                                  |
| `PAPERLESS_TARMED_PUBLIC_URL`                          | Paperless's browser address, for the notification's link                                                   |
| `PAPERLESS_NETWORK`, `PAPERLESS_TARMED_IMAGE`, `TZ`    | compose only                                                                                               |

`compose.yaml` passes only the variables it lists. `PAPERLESS_TARMED_SINCE`,
`_PATIENT_FUZZY`, `_CURRENCY` and `_TIMEOUT` are not among them, so in the
container give `--since` explicitly.

## Operations

**Updating**: push to Forgejo. Within 15 minutes the `build-images` job
(`scripts/jobs.conf`) rebuilds `paperless-tarmed:0.1.0` and the dashboard light
turns amber ("update waiting"). Portainer → **Pull and redeploy** turns it green;
red means the container is gone.

**Tariff table**: the official list of tariff types, kept only to see what
changed. Nothing reads it for categories or labels; those are hardcoded in
`tariffs.py`. A refresh prints the codes added, removed or renamed, so a new
one can be added there:

```bash
docker exec paperless-tarmed paperless-tarmed refresh-tariffs --dry-run
docker exec paperless-tarmed paperless-tarmed refresh-tariffs
```

Writes `/data/tariff_types.json`, the baseline for the next refresh's
comparison; it survives redeploys and wins over the image's copy. Needs
`www.forum-datenaustausch.ch`, the only outbound access.

**Local use** (Python 3.11+): `python3 -m venv .venv && .venv/bin/pip install -e
".[dev,serve]" && cp .env.example .env`.

## Troubleshooting

| Symptom                                                         | Fix                                                                                            |
| --------------------------------------------------------------- | ---------------------------------------------------------------------------------------------- |
| `No field mapping configured` / `maps unknown value(s)`         | Set or fix `PAPERLESS_TARMED_FIELDS`; `fields` lists valid keys.                               |
| `Custom field 'X' not found (or ambiguous)`                     | Name mismatch; run `fields`. Locally, a stale shell export beats `.env`.                       |
| `Document type '…' not found on this instance`                  | Create it, or fix `PAPERLESS_TARMED_DOCUMENT_TYPE` / `--document-type`.                        |
| `Refusing to select the entire archive`                         | Add `--document-type` / `--tag` / `--query` / `--id`, or set `PAPERLESS_TARMED_DOCUMENT_TYPE`. |
| `report`/`apply` see few documents                              | No selection flag = cache only; add `--document-type`.                                         |
| Bodyless **400** from every API call                            | `webserver` missing from `PAPERLESS_ALLOWED_HOSTS` (Gotchas).                                  |
| Writes to `/data` fail silently                                 | Data directory not owned by uid 1000.                                                          |
| Webhook 401 / 400 / 503                                         | Secret mismatch / body not `{"doc_id": {{doc_id}}}` or "Use parameters" on / secret unset.     |
| Paperless cannot reach `paperless-tarmed:8000`                  | Not on the same network; compare `PAPERLESS_NETWORK` with `docker network ls`.                 |
| `… is not an option of select field …`                          | Add the option, or use a Text field.                                                           |
| Every document: `no 'Justificatif de remboursement' page found` | No text layer; check Paperless OCR.                                                            |
| SSL errors                                                      | Use `http://webserver:8000`, or `PAPERLESS_TARMED_VERIFY_SSL=0`.                               |
| `ModuleNotFoundError: paperless_tarmed` locally                 | venv built elsewhere; recreate `.venv`.                                                        |

## Gotchas

- **Use Document Added, not Document Updated.** With `WEBHOOK_OVERWRITE` / `WEBHOOK_TITLE`, an update trigger makes the webhook revert manual edits on every update (and rename files if `PAPERLESS_FILENAME_FORMAT` uses the title).
- **Portainer never builds this image** (`pull_policy: never`, no `build:` in compose): its rebuilds were unreliable and silently kept old code. Only the `build-images` job builds; a redeploy with no image fails with "No such image" — run the job (or `scripts/build-images.sh paperless-tarmed=paperless-tarmed:0.1.0`) first. Which code is running: `docker exec paperless-tarmed grep -c <new string> /usr/local/lib/python3*/site-packages/paperless_tarmed/<file>.py`.
- **`webserver` must stay in Paperless's `PAPERLESS_ALLOWED_HOSTS`** (`stacks/paperless/compose.yaml`). Otherwise Django answers a bodyless 400 and logs nothing.
- **The repo root ignores `**/data/`.** This directory's `.gitignore`re-includes`paperless_tarmed/data/` with a directory-level negation; a file-level one silently does nothing.
- **`/hook` has no network-level auth** and no Authelia: anything on `proxy` can POST; the secret is the only guard.
- **Logs can contain patient data** (names in warnings, dates, amounts), and there is no `logging:` block, so Docker keeps them indefinitely.
- **`samples/` and `*.csv` are gitignored on purpose**: they hold patient data (`report --csv` too). Never force-add them.

## Layout

| Module                                  | Role                                                                                                                            |
| --------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------- |
| `values.py`, `models.py`                | value names; data classes                                                                                                       |
| `text.py`, `locate.py`, `extract.py`    | PDF text → justificatif pages → regexes                                                                                         |
| `normalize.py`                          | name matching, provider shortening                                                                                              |
| `confidence.py`                         | plausibility checks, final values, title                                                                                        |
| `catalogue.py`                          | the category rule, TARDOC group labels, `report`'s summary; reads `data/catalogue.json` (built by `scripts/build_catalogue.py`) |
| `tariffs.py`, `refresh.py`              | tariff grouping and table; `refresh-tariffs`                                                                                    |
| `pipeline.py`                           | one extraction path for CLI and webhook                                                                                         |
| `planning.py`                           | what to write, review tag, journal (CLI and webhook)                                                                            |
| `cache.py`, `paperless.py`, `report.py` | local cache; API client with retries; quality table                                                                             |
| `cli.py`, `app.py`                      | CLI; webhook                                                                                                                    |
