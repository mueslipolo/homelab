# Tab gophers

One Go gopher per dashboard tab, named after the tab (`<tab>.png`, 200 px),
shown in the corner of the open tab.

| File           | Gopher                    | Source                              |
| -------------- | ------------------------- | ----------------------------------- |
| `services.png` | with a welding torch      | Free Gophers Pack, characters/45    |
| `storage.png`  | with a piggy bank         | Free Gophers Pack, illustrations/25 |
| `backups.png`  | under an umbrella in rain | Free Gophers Pack, characters/43    |
| `system.png`   | with a wrench             | Free Gophers Pack, characters/59    |
| `network.png`  | with wifi waves           | Free Gophers Pack, characters/52    |
